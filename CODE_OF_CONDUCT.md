# Code of conduct

Everybody who takes part in Chokh, in its issues, pull requests, discussions
and anywhere else it gathers people, is held to the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
Its text is the standard; this page only says how it is applied here.

## Reporting

To report behaviour that breaks it, use the repository's private reporting
form, which only the maintainers see:
**[Report privately](https://github.com/chokh-analytics/chokh/security/advisories/new)**.
Say in the title that it is about conduct, not security. It is kept between you
and the maintainers.

## Enforcement

The maintainers decide what happens, following the Contributor Covenant's
enforcement guidelines: a correction, a warning, a temporary ban or a
permanent one, by how serious it was and whether it was repeated.
