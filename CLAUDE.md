# CLAUDE.md

Read [AGENTS.md](AGENTS.md) first and follow it exactly. It is the canonical
rulebook for this repository: what Chokh is, the repository rules review
refuses, the stack, the layering, the API envelope and the execution contract.

Then read, in order:

1. `README.md` for the shape of the product.
2. `ANALYTICS_TASKS.md` in the Progsity workspace (`E:\Progsity Dev`) for the
   ticket you are on. That file owns the tickets, their order and their
   acceptance.
3. ADR-0069 in that workspace and the artifact "Chokh Analytics Plan"
   sections 3 to 7 for the reasons, the data model, the API contract and the
   dashboard rules.

One ticket per session. Nothing beyond the ticket. If a ticket cannot be done
as written, stop and report rather than picking an alternative.
