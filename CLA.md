# Contributor Licence Agreement

Thank you for contributing to Chokh. This agreement lets BWJ Tech Ltd. keep
publishing the project and keep deciding how it is licensed, including moving a
part of it between the MIT core and `packages/ee/`. Without it the company
would lose that decision the day the first outside patch merges, and the
project would lose the option of ever changing its mind.

It is adapted from the Apache Individual Contributor Licence Agreement, which
is the one most people have already signed somewhere.

**You keep the copyright in what you write.** This grants a licence, it does
not take ownership.

## How to sign it

Add one row to [CLA-SIGNATURES.md](CLA-SIGNATURES.md) in the same pull request
as your first contribution. The commit is signed by your own git authorship,
which is what proves you agreed to this. CI refuses a pull request whose
authors are not on that list.

If you are contributing on behalf of a company, put the company name in the
"Signing as" column. The person adding the row represents that they are
authorised to bind it.
